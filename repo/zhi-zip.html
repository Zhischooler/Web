多格式支持

单文件多选、文件夹递归压缩，保留完整相对目录结构。

防覆盖机制

自动保留文件相对目录结构，避免同名文件冲突，安全可靠。

异步处理

后台线程压缩，界面流畅不卡顿，实时显示进度条。

累加操作

支持分批次添加文件或文件夹到压缩列表，灵活高效。

快速使用

  • 点击 “添加文件” 或 “添加文件夹”
  • 状态栏显示已添加文件数量
  • 点击 “开始压缩”，选择保存路径及文件名
  • 等待进度条完成，即可获得 .zip 压缩包
支持 Ctrl / Shift 多选文件

环境依赖

  • Python 3.8+
  • PySide6
安装依赖
pip install PySide6
运行源码
python Zhi-zip.py
