Greatclass Recorder

屏幕录制 · 白板 · 标注 · 文本输入 · 图片导入 · MP4 导出。 录制时在白板上画下的每一笔都会进入视频，全程本地运行，不上传、不写盘。

开始安装 → GitHub
$ git clone https://github.com/Zhischooler/Greatclass-Recorder.git
功能特性

录制，同时能画

不是单纯的录屏工具。录制过程中叠加的白板、标注、文本和图片，都会一并写进视频。

⏺

屏幕 + 麦克风录制

由 ffmpeg 驱动，实时 H.264 编码。Windows 用 gdigrab、Linux 用 x11grab、macOS 用 avfoundation，音频同步采集。

✏️

白板与标注

内置 Pen / Line / Rectangle / Arrow / Eraser / Select 工具，可调笔色与笔宽，适合讲解、圈画和演示。

🖼

图片导入

支持 PNG / JPG / JPEG / BMP / GIF / WEBP。切到 Select 模式即可拖动位置，或用右下角把手缩放。

⌨️

文本输入

Text 工具点击画布任意位置即出现输入框，回车确认，文字直接叠加到录制画面上。

🎬

MP4 导出

停止录制后文件先存入系统临时目录，再通过 Export Video 选择路径重新编码输出 MP4。

🔒

本地运行

视频只留在本机临时目录，不上传任何数据。导入的图片仅存在于内存白板状态，从不写入磁盘。

快速开始

安装与运行

需要 Python 环境，以及一个可用的 ffmpeg 二进制文件。ffmpeg 必须自行准备。

1

创建虚拟环境并安装依赖

requirements.txt 中只有一项依赖：PySide6>=6.5.0。 

$ python -m venv .venv
$ source .venv/bin/activate          # Windows: .venv\Scripts\activate
$ pip install -r requirements.txt
2

准备 ffmpeg（必需）

程序按以下顺序查找 ffmpeg：bin/ffmpeg.exe（Windows）→ bin/ffmpeg（Linux / macOS）→ 系统 PATH 中的 ffmpeg。 

$ wget -c https://johnvansickle.com/ffmpeg/releases/ffmpeg-release-amd64-static.tar.xz
$ tar -xf ffmpeg-release-amd64-static.tar.xz
$ mkdir -p bin
$ mv ffmpeg-*-amd64-static/ffmpeg bin/
$ chmod +x bin/ffmpeg
$ brew install ffmpeg
$ mkdir -p bin
$ cp "$(which ffmpeg)" bin/ffmpeg
> Invoke-WebRequest -Uri "https://www.gyan.dev/ffmpeg/builds/ffmpeg-release-essentials.zip" -OutFile "ffmpeg.zip"
> Expand-Archive ffmpeg.zip -DestinationPath .
> New-Item -ItemType Directory -Force -Path .\bin | Out-Null
> Copy-Item .\ffmpeg-*\bin\ffmpeg.exe .\bin\
> Remove-Item -Recurse .\ffmpeg-*

验证是否就位： 

$ ./bin/ffmpeg -version
# Windows:
> .\bin\ffmpeg.exe -version
3

启动

在项目根目录执行： 

$ python -m recorder
使用方法

从选笔到导出 MP4

打开主窗口后，工具栏从左到右提供全部绘制与录制控制。

  1. 选择工具 工具栏提供 Pen / Line / Rectangle / Arrow / Text / Eraser / Select 七种模式。
  2. 调整笔色与粗细 用 Color 更改画笔颜色，用 Width 数值框调整笔的粗细。
  3. 导入图片 Import Image 支持 PNG / JPG / JPEG / BMP / GIF / WEBP。导入后切换到 Select 模式，可拖动图片，或通过右下角把手缩放。
  4. 插入文字 选择 Text 工具，点击画布任意位置弹出输入框，按 Enter 确认。
  5. 开始录制 点击 Start Recording，ffmpeg 开始捕获屏幕（含麦克风）。白板上画的一切——笔迹、标注、文本、图片——都会被录进视频。
  6. 停止录制 点击 Stop Recording，视频保存到系统临时目录。
  7. 导出视频 点击 Export Video，选择目标路径，写出一个 MP4 文件。
录制原理

各平台采集方式

视频与音频源按操作系统分别适配，全部通过 ffmpeg 完成。

平台 视频源 音频源
Windows gdigrab -draw_mouse 1 -i desktop dshow（自动检测麦克风）
Linux x11grab -draw_mouse 1 -i $DISPLAY pulse 默认设备
macOS avfoundation -capture_cursor 1 -i 1:0 同一 avfoundation 音轨

停止录制时，程序会向 ffmpeg 的标准输入写入 q，让 ffmpeg 完成文件收尾并写入 moov atom。若 1.5 秒内仍未退出，则强制结束进程。

常见问题

排查与调优

以下问题在 README 中有明确说明。

只录到音频，没有画面

检查你的 ffmpeg 是否支持 gdigrab（Windows）或 x11grab（Linux）。

$ ffmpeg -devices

确认输出列表中包含对应设备。

录制没有声音

Windows 上如果找不到麦克风，dshow 会在无音频的情况下静默录制。用下面的命令列出音频设备，然后手动指定： 

# Windows
> .\bin\ffmpeg.exe -list_devices true -f dshow -i dummy

# Linux
$ ./bin/ffmpeg -f x11grab -i $DISPLAY -t 3 test.mp4
$ ./bin/ffmpeg -f pulse -i default -t 3 test.wav

# macOS
$ ./bin/ffmpeg -f avfoundation -list_devices true -i ""

拿到设备名后，修改 recorder_engine.py 中的 -i audio=xxx 参数。 macOS 首次运行时，需要给终端或应用授予麦克风权限。

录制文件太大

recorder_engine.py 中 -crf 默认为 23。调到 28 可以显著减小体积。

也可以把 -framerate 降到 15。

录制和导出有什么区别？

录制 = 屏幕捕获 + 实时 H.264 编码，写入临时文件。
导出 = 用 ffmpeg 对那个临时文件重新编码，保存到你选择的路径。

两者使用的是同一个 ffmpeg 二进制文件。

导出后文件没有变小？

packer.py 会执行重新编码。如果找不到 ffmpeg，它会退化为直接复制文件。

数据与隐私

东西都留在你自己的机器上

这个工具不联网、不上传，也不生成任何形式的课程数据。

录制的视频只留在本地临时目录，不会上传到任何地方。

不产生课程 JSON，输出只有 MP4 文件。

导入的图片只存在于内存中的白板状态，从不写入磁盘。
